# S-Faerûn VF

Module maison de Shadou pour la campagne **L'épopée de Faerûn** (Foundry VTT v13/v14, système dnd5e).

## Ce qu'il fait
1. **États et règles en français** : les liens automatiques vers les états (À terre, Étourdi, Épuisement…) et les règles pointent vers le SRD 2024 français (`dnd5e.content24`) au lieu des pages anglaises du Manuel des joueurs.
2. **Vitrine des options de personnage** : les classes, sous-classes, espèces, historiques et dons rangés dans les objets du monde sont recopiés automatiquement dans le compendium du monde « Options de personnage (VF) » (au démarrage et à chaque modification). Les objets du monde restent la seule version de référence ; le compendium peut être supprimé, il est reconstruit.
3. **Sources en double masquées** : dans le navigateur de compendiums (« Ajouter une classe », « Ajouter une espèce »…), seules ces options sont proposées.

Chaque fonction peut être désactivée dans les réglages du module.
